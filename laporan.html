Langkah-Langkah

  • Export konten group WhatsApp menjadi file teks.
  • Pindah file data_group.txt ke direktori ums-l200220036.github.io pada WSL.
  • Menyiapkan kode program. Lihat Kode Program
  • Menjalankan kode clustering di WSL dengan perintah: 
    python clustering.py run --n_clusters 3 --output_csv hasil_klaster.csv
  • Hasil Analisis
    • Jumlah Pesan
      • Total pesan yang dimuat dari file log WhatsApp: 10.523 pesan.
      • Setelah proses pembersihan, jumlah pesan berkurang menjadi 10.183 pesan.
      • Penurunan pesan: 340 pesan dihapus selama proses pembersihan.
    • TF-IDF Vectorization
      • TF-IDF menghasilkan matriks dengan bentuk (10.183, 5.763).
      • 10.183: Jumlah pesan setelah pembersihan.
      • 5.763: Jumlah fitur (kata unik) yang dihasilkan setelah proses vektorisasi.
    • Klasterisasi
      • Algoritma KMeans berhasil mengelompokkan pesan ke dalam 3 klaster:
        • Klaster 0: 9.291 pesan.
        • Klaster 1: 842 pesan.
        • Klaster 2: 50 pesan.
      • Analisis:
        • Klaster 0 dan 1 mencakup sebagian besar pesan dengan tema umum.
        • Klaster 2 merupakan konten media yang, mengapa begitu? karena saya tidak menyertakan media saat export data group.
    • Kata Teratas per Klaster
      • Klaster 0: null, aku, mas (tema informal).
      • Klaster 1: kandani, og, ogh (istilah slang).
      • Klaster 2: media, disertakan, tidak (konten media).
    • Penyimpanan Hasil
      • Hasil klasterisasi disimpan ke file CSV: hasil_klaster.csv.
